===============================================
  GREEN VALLEY PUBLIC SCHOOL - WEBSITE
===============================================

Modern, fully responsive school website.

HOW TO USE:
1. Extract the ZIP file
2. Open the folder "school-website"
3. Double-click on "index.html" to open in browser
   OR
   Use any local server (Live Server in VS Code recommended)

PAGES INCLUDED:
- Home (index.html)
- About Us
- Academics
- Admissions (with enquiry form)
- Facilities
- Gallery
- Contact (with contact form)

FEATURES:
- Fully responsive (Mobile + Tablet + Desktop)
- Sticky navigation bar
- Mobile hamburger menu
- Modern green + blue color theme
- Clean professional design
- Working form alerts (demo)

CUSTOMIZATION:
- Change school name, address, phone in all HTML files
- Replace placeholder icons/images with real photos
- Update fee structure and content as needed
- Add Google Maps iframe in contact.html

Created with pure HTML, CSS & JavaScript (no frameworks required).
